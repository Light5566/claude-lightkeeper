# Export & Import

## What it is

Getting content out as HTML, PDF or ZIP, and bringing ZIP exports back in.

## Modules

- [[Exports]] — Any page, chapter or book can be exported as contained HTML, plain text, PDF or a portable ZIP
- [[Import]] — A ZIP export from any BookStack instance can be uploaded, validated and imported as new content
