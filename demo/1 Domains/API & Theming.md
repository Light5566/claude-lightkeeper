# API & Theming

## What it is

The REST API and the theme system that customises the instance.

## Modules

- [[REST API]] — A token-authenticated REST API over the same controllers' API variants, with generated docs
- [[Theme System]] — A theme folder can override views, add custom head content and hook into named events without changing the application code
