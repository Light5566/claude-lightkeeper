# Users & Settings

## What it is

User accounts, preferences, instance settings, maintenance and the audit log.

## Modules

- [[Users]] — User accounts, their profile pages and the admin screens that manage them
- [[User Preferences]] — Per-user choices: language, dark mode, keyboard shortcuts, notification preferences and the user's own account settings
- [[Settings]] — Instance-wide settings: name, branding, registration, features
- [[Maintenance]] — Admin maintenance actions (cleanup, test email, regenerate references) and the status endpoint monitors poll
- [[Audit Log]] — The admin view over the activity table: who did what, when, from which IP
