# Search & References

## What it is

Finding content: the search index and the cross-links between pages.

## Modules

- [[Search]] — Full-text search over all content with filters and term syntax
- [[References]] — Cross-links between pages are stored so a page can list where it is referenced, and links are rewritten when a target moves
